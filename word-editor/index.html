How to edit a Word document online

  1. Open a .docx file, or start a new document.
  2. Edit like in Word: styles, fonts, lists, tables, pictures, links and page breaks.
  3. On phones, switch to the mobile view that fits text to the screen.
  4. Download as Word (.docx) or PDF.

Features

  • Paragraph styles, fonts, sizes, colours, highlight
  • Bullets and numbering with levels
  • Tables, pictures, links, page breaks, page numbers
  • Page size and margins
  • Keeps the original file’s styles, headers and footers
  • Save as .docx or PDF

Questions

Do I need Microsoft Word or an account?

No. The editor runs in the browser and needs no account.

Can I open .doc files?

Old binary .doc files need to be saved as .docx first.
